# Food Delivery System

## Purpose of the Application

This application is a simple backend receipt generator for a Food Delivery System.

The program collects customer information, calculates the subtotal, service charge, delivery charge, and displays the final receipt.

## Tech Stack

- Python 3
- GitHub
- Visual Studio Code / GitHub Codespaces

## Project Files

- `main.py` - Runs the main application.
- `customer.py` - Collects customer information and determines prices.
- `receipt.py` - Calculates and prints the receipt.

## How to Use

1. Open the project folder.
2. Open the terminal.
3. Run the following command:

```bash
python main.py
